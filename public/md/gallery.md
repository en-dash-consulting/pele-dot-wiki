# Every diagram type, drawn live

> Gallery of all 32 Mermaid diagram types drawn live by Pele: flowchart, sequence, class, Gantt, sankey, C4, Wardley and more. Edit each, compare with Mermaid.js.

Source: https://pele.wiki/pages/gallery.html · Last updated 2026-10-17

All 32 diagram types built into Mermaid 12.1.0, drawn by Pele as this page loaded. Edit any of them, or compare it with Mermaid.js.

*(Interactive demo: open https://pele.wiki/pages/gallery.html)*

## About these examples

The everyday types (flowchart, sequence, class, state, ER, Gantt, pie, git graph, mindmap, timeline, journey, kanban, XY and quadrant charts) are written for this site. The rest are taken from Mermaid's documentation (MIT license), through Pele's own test suite. Pele also supports `info`, which prints its version, and is left out here.

Pele draws everything with its own layout and look, so the Mermaid.js version of each diagram will look different. That's expected; see [compatibility](/pages/migrating.html#what-looks-different).
