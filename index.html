Live demos of Pele

Pele is kepano's open-source library that renders Mermaid diagrams to SVG, themed with CSS variables. The official docs at pele.run are excellent and the place to start: a playground, the full API, every diagram type, and the thinking behind it. This independent site is a companion to them. It runs the real package in your browser next to Mermaid.js, so you can see the difference for yourself.

What is Pele?

Pele is a JavaScript library that turns Mermaid diagram text into SVG. kepano wrote it for Obsidian, so that diagrams draw instantly and match the user's theme. MIT licensed.

It takes the same text you would give Mermaid.js and returns an SVG string, synchronously:

import { render } from 'pele'

const { svg } = render(`flowchart LR
  A[Mermaid text] --> B[SVG]`)
document.querySelector('#diagram').innerHTML = svg

It supports every diagram type built into Mermaid 12.1.0, uses its own layout, and takes colours and fonts from CSS variables. More in What is Pele? and Getting started.

Where it helps

Pele's speed matters when diagrams are drawn often, live, or in bulk:

  • an editor preview that redraws on every keystroke;
  • a chat app streaming a diagram from a model;
  • an app whose diagrams must follow the user's theme;
  • diagrams read on phones;
  • documentation with hundreds of diagrams on a page;
  • diagrams written by people you don't trust.

Keep Mermaid.js if you need its exact look, JavaScript click callbacks, or plugins such as ZenUML. See Pele vs Mermaid.js.
