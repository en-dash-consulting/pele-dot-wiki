kepano's Mermaid renderer · explained, live

Pele draws Mermaid diagrams as fast as you can type

Pele is kepano's open-source Mermaid renderer, built for Obsidian. It reads the Mermaid syntax you already write and returns SVG in a fraction of a millisecond, with no dependencies and colours set by CSS. Try it below.

Race it live ↓ npm install pele

Type a diagram. Watch who keeps up.

Both renderers redraw on every keystroke. Pele is synchronous, so it finishes before your next key. Mermaid.js works asynchronously and falls behind.

Pele is an open-source library by kepano (Steph Ango, CEO of Obsidian) that renders Mermaid diagram text to SVG. pele.wiki is an independent, hands-on guide: every demo runs the real Pele package next to Mermaid.js, so you can see when the difference matters.

What is Pele?

Pele is a drop-in renderer for Mermaid syntax. You hand it the same text you would give Mermaid.js and it hands back an SVG string, synchronously:

import { render } from 'pele'

const { svg } = render(`flowchart LR
  A[Mermaid text] --> B[SVG]`)
document.querySelector('#diagram').innerHTML = svg

It supports every diagram type built into Mermaid 12.1.0, draws them with its own layout and style, and takes its colours and fonts from CSS variables. See What is Pele? for the details, or Getting started to add it to an app.

When does it matter?

When diagrams are drawn often, live or at scale: a preview that redraws on every keystroke, a chat app streaming a diagram from an AI model, a docs page with dozens of diagrams, or an app that must match a user's theme. If you need Mermaid.js's exact look or its click callbacks, stay with Mermaid.js.
