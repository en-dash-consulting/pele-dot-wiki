What is Pele?

Pele is a JavaScript library that turns Mermaid diagram text into SVG. It was written by kepano (Steph Ango, CEO of Obsidian) so that diagrams in Obsidian draw instantly and match the user's theme. It is open source under the MIT license.

You hand it the same text you would give Mermaid.js and get an SVG string back, synchronously:

import { render } from 'pele'

const { svg } = render(`flowchart LR
  A[Mermaid text] --> B[SVG]`)
document.querySelector('#diagram').innerHTML = svg

It supports every diagram type built into Mermaid 12.1.0, uses its own layout and look, and takes colours and fonts from CSS variables. What is Pele? has the details; Getting started gets it into your app in five minutes.

When is Pele the better choice?

When diagrams are drawn often, live or in bulk:

  • a preview that redraws on every keystroke, like the race above;
  • a chat app streaming a diagram from an AI model (stop 2);
  • an app whose diagrams must follow the user's theme (stop 3);
  • diagrams read on phones (stop 4);
  • docs pages with dozens or hundreds of diagrams (stop 5);
  • diagrams written by people you don't trust (stop 6).

Stay with Mermaid.js if you need its exact look, JavaScript click callbacks or plugins such as ZenUML. The Pele vs Mermaid.js page goes through it honestly.
